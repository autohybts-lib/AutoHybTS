Where the data come from
------------------------

The library does not bundle any real series: each one is downloaded the first time it
is requested, cached, and read from there afterwards. There are four sources:

.. list-table::
   :header-rows: 1
   :widths: 16 48 36

   * - Provider
     - Source
     - License
   * - synthetic
     - generated on the fly by ``autohybts.datasets.synthetic`` (numpy, ``seed=42``);
       nothing is downloaded
     - part of AutoHybTS
   * - ``rdatasets``
     - `Rdatasets <https://vincentarelbundock.github.io/Rdatasets/>`_: a site that
       publishes the datasets of hundreds of R packages as CSV. The address of each CSV
       comes from the ``Rdatasets/datasets.csv`` index
     - that of the source R package
   * - ``m4``
     - official CSVs of the M4 competition in the
       `Mcompetitions/M4-methods <https://github.com/Mcompetitions/M4-methods>`_
       repository (``Dataset`` folder): ``M4-info.csv``, ``<Freq>-train.csv`` and
       ``<Freq>-test.csv``
     - M4 competition data (Makridakis et al.)
   * - ``m3``
     - file of the R package `Mcomp <https://cran.r-project.org/package=Mcomp>`_ 2.8 on
       CRAN, read in Python by the ``rdata`` library (``datasets`` extra); R is not
       required
     - GPL-3 (``Mcomp`` package); M3 competition data (IIF)

In the *Source* column, ``package::name`` is the R package and the object name, as
written in R. ``datasets`` is the package that ships with R; ``DAAG`` is the package of
the book *Data Analysis and Graphics Using R*. Both come through Rdatasets, and R does
not need to be installed. ``get_data("ozone")`` is equivalent to
``load_dataset("rdatasets", package="DAAG", name="ozone", target="Annual",
time_col="Year", frequency="YS")``. The manifest of each cached file stores the URL,
the license and the provider version.

To see the full catalogue of each provider:

.. code-block:: python

   from autohybts.datasets import list_datasets

   list_datasets()                                  # providers (no download)
   list_datasets("m4", subset="daily")
   list_datasets("rdatasets", search="ozone")

Cache and security
------------------

* Files go to ``~/.cache/autohybts/datasets`` (or ``AUTOHYBTS_DATA_DIR``), one folder
  per provider. Nothing is downloaded at install time or on ``import``.
* HTTPS only, only domains approved per provider, with a timeout, few retries and a
  maximum size. Redirects must also stay on HTTPS and on the approved domains.
* Package and dataset names become file names in the cache and accept only letters,
  digits and ``._+-`` (no ``/``, ``\`` or ``..``).
* Each file has a manifest (URL, access date, SHA-256, size, license, version). A file
  changed after download is refused (``DatasetIntegrityError``); the daily M4 files and
  the ``Mcomp`` package have their checksum pinned in the code.
* ``offline=True`` uses only the cache and says what is missing
  (``DatasetUnavailableError``).
* Files without a pinned hash are trusted on first download; make that download on a
  trusted network.

M4
--

.. code-block:: python

   from autohybts import AutoHybridExperiment
   from autohybts.datasets import list_datasets, load_benchmark

   list_datasets("m4", subset="daily")
   series = load_benchmark("m4", subset="daily", series_id="D1")
   series.train, series.test, series.descriptor.horizon

   exp = AutoHybridExperiment(fh=series.descriptor.horizon,
                              test_size=len(series.test)).fit(series.full())

``full()`` joins the training data and the official test; ``test_size=len(series.test)``
seals the official test. M4 dates come from ``M4-info.csv`` (two-digit years, known to
be unreliable); when they do not form a valid index, a synthetic calendar is used and
``descriptor.extra["index_source"] == "synthetic"``.

M3
--

From the R package ``Mcomp`` (CRAN, GPL-3). Reading the R file requires the
``datasets`` extra.

.. code-block:: python

   from autohybts.datasets import load_benchmark

   m3 = load_benchmark("m3", subset="monthly")      # BenchmarkDataset
   panel = m3.panel(m3.series_ids[:5])              # PanelFrame, official tests at the end

Other Rdatasets series
----------------------

Outside the table above, Rdatasets is a heterogeneous catalogue: the library does not
guess which column is time and which is the target. Look at the raw table and name
both, with the frequency:

.. code-block:: python

   from autohybts.datasets import load_dataset, raw_dataset

   raw_dataset("rdatasets", package="datasets", name="AirPassengers")   # columns: time, value
   air = load_dataset("rdatasets", package="datasets", name="AirPassengers",
                      target="value", time_col="time", frequency="MS")
   y = air.full()                                   # load_dataset returns a BenchmarkSeries

Time in decimal years (R ``ts`` objects) is converted to ``YS``, ``QS`` or ``MS`` and
checked; dates as text go through ``pd.to_datetime``.

Tables without a date column, such as ``airquality`` (only ``Month`` and ``Day``), are
assembled by hand from the raw table:

.. code-block:: python

   import pandas as pd

   d = raw_dataset("rdatasets", package="datasets", name="airquality")
   idx = pd.to_datetime(dict(year=1973, month=d["Month"], day=d["Day"]))
   oz = pd.Series(d["Ozone"].to_numpy(), index=idx, name="Ozone").asfreq("D")
   oz = oz.interpolate(limit_direction="both")      # 37 missing days: choose how to handle them

.. note::

   The library does not fill missing values. A series with ``NaN`` is refused at
   ``fit`` (``DataValidationError``); handle missing values first.

.. warning::

   The license of each Rdatasets dataset is that of the source R package. The library
   does not redistribute data: check the source before republishing.
